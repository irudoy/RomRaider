Building RomRaider
==================

Requirements
------------

* Git
* A JDK 17 or newer installation that matches the operating system architecture
* Apache Ant 1.10.x, including its optional tasks

Set JAVA_HOME to the JDK installation and add both JAVA_HOME/bin and
ANT_HOME/bin to PATH. Verify the toolchain before building:

    java -version
    javac -version
    ant -version

The Java and javac commands must both report version 17 or newer.

Get the source
--------------

Clone the repository or a personal fork, then run all commands from the
repository root:

    git clone https://github.com/RomRaider/RomRaider.git
    cd RomRaider

Build and test
--------------

Run the deterministic test suite:

    ant unittest

Run the tests and create the Windows and Linux standalone packages:

    ant all

The packages are written below build/dist. The all and standalone targets
run the test suite and stop when a test fails. Use ant help to list the
available targets.

XDF integration test
--------------------

The XDF conversion integration test needs a local directory of XDF files.
It is skipped when the directory is not supplied. Run it with the rest of
the suite by setting the Ant property:

    ant -Dromraider.test.xdfDir=/path/to/xdf-definitions unittest

Container build
---------------

The Dockerfile provides the same Java 17 and Ant environment used by CI:

    docker build --tag romraider-builder .
    docker run --rm --user "$(id -u):$(id -g)" \
        --volume "$PWD:/home/romraider/RomRaider" \
        romraider-builder ant all

macOS Apple Silicon application
-------------------------------

The macOS application requires an ARM64 JDK 17 or newer and Apache Ant. Build
and install it from the repository root:

    tools/macos/install-macos-app.sh --launch

Use --app to select a destination other than /Applications/RomRaiderHD.app.
See tools/macos/README.md for theme, runtime, and packaging details.

IDE setup
---------

Import the repository as an existing Java project in Eclipse, IntelliJ IDEA,
or Visual Studio Code. Configure the project JDK as Java 17. Run ant all once
after importing so that generated sources and build outputs are available.

Contributing
------------

Create a branch in a personal fork, add tests for behavior changes, and run
ant all before opening a pull request. Keep the branch current with the
upstream master branch.
